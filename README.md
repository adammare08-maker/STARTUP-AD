# STARTUP/AD

Landing page de STARTUP/AD, construite avec TypeScript, React, Vinext et Tailwind CSS.

## Lancer le site localement

```bash
npm install
npm run dev
```

Ouvrez ensuite `http://localhost:3000`.

## Vérifier la version de production

```bash
npm run build
```

## Éléments à personnaliser

- Remplacer les trois créations de démonstration dans `app/page.tsx`.
- Remplacer l’emplacement photo d’Adam.
- Configurer l’adresse email et les liens LinkedIn / Instagram.
- Connecter le formulaire dans `components/contact-form.tsx` à un service d’email.
- Compléter les mentions légales et la politique de confidentialité avant publication publique.
